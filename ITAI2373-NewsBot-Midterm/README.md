# ITAI 2373 — NewsBot Midterm Project

## Project Overview
NewsBot is a Natural Language Processing (NLP) project that analyzes BBC news articles using text preprocessing, machine learning, and other NLP techniques.

## Dataset
The project uses 1,490 BBC news articles from five categories:
- Business
- Entertainment
- Politics
- Sport
- Technology

## Project Objectives
- Explore and check the dataset.
- Clean and preprocess news article text.
- Analyze text using NLP techniques.
- Apply and evaluate machine learning models.
- Present analysis results and visualizations.

## Tools and Technologies
- Python
- Google Colab / Jupyter Notebook
- Pandas
- NLTK and spaCy
- Scikit-learn
- Visualization libraries used in the notebook

## Project Files
- `ITAI2373_NewsBot_Midterm.ipynb` — notebook containing code, analyses, outputs, and reflections.
- `README.md` — project overview and contributions.

## How to Run
Open the notebook in Google Colab or Jupyter Notebook and run the cells in order. Follow the notebook's instructions for loading the dataset and downloading any required NLP resources.

The notebook contains the required analyses, visualizations, model evaluation, and observations.
