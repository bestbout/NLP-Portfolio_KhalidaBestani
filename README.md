# NewsBot Intelligence System — ITAI 2373 Midterm

## Project Overview

NewsBot is a Natural Language Processing (NLP) project that analyzes news articles and explores how text-processing techniques and machine learning can help organize news into categories.

The project uses the BBC News dataset containing 1,490 articles in five categories: business, entertainment, politics, sport, and technology.

## Project Objectives

- Explore and prepare a news article dataset.
- Clean and preprocess text for NLP analysis.
- Analyze important words and TF-IDF features.
- Apply machine learning models to news classification.
- Explore named entity recognition and sentiment analysis.
- Evaluate results using the required metrics and visualizations.
