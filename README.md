# NLP Portfolio

I am an AI student at Houston Community College (HCC), developing my skills in Natural Language Processing (NLP) through coursework and hands-on projects. In this course, I explore text preprocessing, sentiment analysis, text classification, named entity recognition, and machine learning techniques.

This portfolio showcases coursework, experiments, and projects using Python, NLTK, spaCy, and Scikit-learn to analyze text data and understand how AI can process human language.
